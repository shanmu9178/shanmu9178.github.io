关于本站

📌 站点简介

这是一个简简单单、随手搭建的个人小站点，没有复杂功能，没有花哨内容。

纯粹用来记录生活、存放相册、收藏资源、分享自用工具的小众小破站。

🛠 搭建信息

搭建技术：原生 HTML + CSS + JavaScript

部署方式：轻量化静态网页部署

设计风格：深色极简、毛玻璃美化、简约高级风

✨ 现有功能

1. 分类相册：截图、日常、PNG图片分类浏览

2. 全局背景音乐：全站统一背景音乐播放控制

3. 多页面布局：相册、留言、音乐、工具、资源等多页面

4. 全端适配：完美适配手机、平板、电脑设备

📅 更新说明

持续优化页面美化、交互动效、功能新增与BUG修复

后续会慢慢补充更多实用工具与资源内容

💬 碎碎念

建站初衷只是兴趣爱好，随缘更新，安静自用。

感谢浏览这个不知名的小破站～
